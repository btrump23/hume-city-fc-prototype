How to open and use this pack

  1. Right-click the zip and choose Extract All first (do not open HTML files from inside the zip, or in OneDrive’s web preview — that is what made the dashboard look unstyled or empty). Then double-click index.html. You do not need a password or a web server.
  2. To preview the public website, open card 1. From there you can also visit the public home and the Boys Program stub.
  3. To try the coach tools, open card 2. It opens straight onto the sample roster — there is no sign-in. Pick a team in the top switcher. If your browser allows it, data stays in this browser only.
  4. To work in a spreadsheet, open card 3. Use sample names only.
  5. Club colours in this pack are red and white (verified from Football Victoria strip lists). The crest is a labelled placeholder, not the official logo.
Privacy: the players in a real girls’ program include minors. Do not type real names, emails, medical notes or phone numbers into this prototype. A production version needs a real login, a hosted database, parent or guardian consent, and consideration of the Australian Privacy Act. Medical notes would also need restricted access and encryption.

Included in this pack

Feature checklist

Everything below is in the Coach Dashboard (and mirrored in the Excel file, except the interactive email and calendar tools). The public Girls page covers the pathway, staff, training, matchday and a call to action.

  • Rosters with player emails, plus parent or guardian contacts (name, relationship, email, phone, and a second contact)
  • Match and training attendance, with a session log and attendance percentage
  • Membership fee status (Unpaid / Part paid / Paid), amount and date
  • Uniform tracking: order status, collection status, and a configurable size
  • Quarterly fitness tracker, with improvement and degradation, configurable periods and metrics
  • Email report of a player’s improvement (preview, mailto, copy, and HTML download)
  • Injury and medical notes, with a follow-up flag and team alert count
  • Match results and basic stats (P, W, D, L, GF, GA, GD, goals, assists, minutes)
  • Weekly training session plan template (save, duplicate, print)
  • Equipment inventory checklist
  • Free-text player development notes
  • Family communication log, with “last contacted” and a 30-day highlight
  • Dribl fixtures import from a CSV export, plus manual entry, countdown, and calendar (.ics) download
  • Player tasks: task sets per team (including a sample Summer Break set), a completion grid, and progress on email reports
  • Fitness tests & assessment: 7 fitness tests and 4 ball-skill tests, squad rankings across Previous / Q1–Q4, green ▲ / red ▼ movement, carry-forward for injury, auto attendance %, a printable confidential report card, and email drafts that are never sent automatically. Sample U9 Girls (Selena) and Under 14s (David Crisp) teams are included, with a “signed in as coach” selector.
  • Club contacts in the coach area: Ozzi (Technical Director) at td@humecityfc.com, plus named coaches with placeholder emails
  • Boys Program stub, ready to extend later using the club’s published pathway names

Dribl (Football Victoria’s competition platform) does not offer a documented public API for automatic sync. Coaches can export events from app.dribl.com via Events → Filter → Export → Exports → Download, then import that spreadsheet here. Official API access would need to be requested from Dribl or Football Victoria. This pack does not scrape Dribl.
